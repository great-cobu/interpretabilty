# MNIST CNN documentation

Stages 1–6 are implemented: uv/Python packaging, validated command-line configuration, MNIST data loading through a PyTorch Lightning DataModule, the CNN, Lightning training/validation, checkpoint resume, and standalone testing. An optional interactive Marimo demonstration is also available. Rich evaluation reports and MLflow integration remain planned.
